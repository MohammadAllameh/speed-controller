# کنترل‌کننده سرعت ویدیو (Video Speed Controller) ⚡

افزونه اختصاصی و پیشرفته برای مرورگرهای **Microsoft Edge** و **Google Chrome** جهت کنترل سرعت پخش تمامی ویدیوها از **0.1x تا 16.0x**.

---

## 🚀 راهنمای نصب در مرورگر Microsoft Edge (در کمتر از ۳۰ ثانیه)

از آنجا که این افزونه اختصاصی خود شماست و در سیستم شما قرار دارد، بدون نیاز به مایکروسافت استور و بدون هیچ هشداری به راحتی نصب می‌شود:

1. **مرورگر Microsoft Edge** را باز کنید.
2. در نوار آدرس بالا، عبارت زیر را تایپ کرده و `Enter` بزنید:
   ```text
   edge://extensions
   ```
3. در منوی سمت چپ (یا بالای صفحه)، گزینه **Developer mode (حالت توسعه‌دهنده)** را روشن (فعال) کنید.
4. روی دکمه **Load unpacked (بارگیری بسته باز نشده)** کلیک کنید.
5. در پنجره باز شده، پوشه زیر را انتخاب کنید:
   ```text
   c:\Speed-Controller
   ```
6. تمام شد! افزونه به لیست افزونه‌های شما اضافه شد. برای دسترسی سریع، روی آیکون پازل (Extensions) در نوار بالای Edge کلیک کرده و علامت سنجاق (Pin) را در کنار **Video Speed Controller** بزنید تا آیکون افزونه همیشه در دسترس باشد.

## 🎯 نحوه استفاده از افزونه

### روش اول: استفاده از پنل گرافیکی (Popup)
- روی آیکون افزونه (⚡) در بالای مرورگر کلیک کنید:
  - با **اسلایدر** سرعت را از 0.1x تا 16x تغییر دهید.
  - از **دکمه‌های سریع (Presets)** مانند `1.5x`، `2.0x`، `3.0x`، `8.0x` یا `16x` استفاده کنید.
  - با دکمه‌های `+0.1` و `-0.1` سرعت را با دقت بالا کم یا زیاد کنید.
  - در صورت تمایل، هر عدد دلخواهی (مثل `2.35`) را مستقیماً تایپ کنید.

### روش دوم: کلیدهای میانبر سریع روی کیبورد (هنگام تماشای ویدیو)
بدون نیاز به باز کردن منو، هنگام پخش ویدیو از کلیدهای کیبورد استفاده کنید:
- **کلید `]`** : افزایش سرعت (0.1+)
- **کلید `[`** : کاهش سرعت (0.1-)
- **کلید `\` یا `R`** : بازنشانی فوری به سرعت عادی (1.0x)
- **کلیدهای `Shift + ]` یا `Shift + [`** : افزایش/کاهش با گام 0.5x
- **کلیدهای `Z` و `X`** : پرش ۵ ثانیه به عقب یا جلو

## ⚙️ ویژگی‌های امنیتی و فنی
- مبتنی بر آخرین استاندارد مرورگرها (**Manifest V3**).
- بدون هیچ‌گونه کد ریموت یا ارسال اطلاعات؛ کاملاً امن و محلی (Local).
- پشتیبانی کامل از یوتیوب، آپارات، اینستاگرام، ویدیوهای فریم‌دار (iFrames) و تمام پلیرهای HTML5.
- امکان حفظ زیر و بمی صدا (Pitch Correction) جهت جلوگیری از تغییر ناخوشایند صدای گوینده.
